check

Listen back with Su-śrotā: what a render says, how far it is from the text, the best of a few seeds, and word timings.

Su-śrotā is IndicConformer fine-tuned on śāstric Sanskrit. Its CTC head covers all 22 IndicConformer languages; Sanskrit is the 256 columns from 4096, with the blank at 5632. The checkpoint’s config names AI4Bharat’s NeMo fork (multilingual tokenizer, multisoftmax decoder), so Ear rewrites it for upstream NeMo: the tokenizer becomes agg, the fork-only keys go, and the weights load non-strict. Only the encoder and the CTC head are used. Install with pip install vachaka[check].

Best of a few seeds

A render whose transcript is far from its text is retried with the next seed; the closest is kept. Recitation.cer records how far it was. The transcript is heard a piece at a time: heard whole, a long run of near-identical lines (a tarpaṇa, the eight quarters of a digvandana) makes the recogniser lose its place, and a good render scored 0.47-0.76.

source

Ear.heard

def heard(
    rec
):

What Su-śrotā hears of rec, each piece of spans on its own, joined.

class _E(Ear):
    def __init__(self): self.got = []
    def hear(self, audio, sr): self.got.append(len(audio)); return 'क'
e, r = _E(), AttrDict(audio=np.zeros(16000*3, np.float32), sr=16000, spans=[(0, 1000), (1500, 3000)])
test_eq(e.heard(r), 'क क'); test_eq(e.got, [16000, 24000])
test_eq(_E().heard(AttrDict(audio=np.zeros(800, np.float32), sr=16000)), 'क')

best_of

def best_of(
    render, ear, text, tries:int=3, max_cer:float=0.08, seed:int=60
):

Call render(seed=…) up to tries times, keeping the render closest to text.

Word timings

Each piece’s words are force-aligned within that piece’s span, so one bad line cannot drag the rest. Words are given as displayed; each is tokenised from its cleaned form, and a word with no Sanskrit tokens (a lone daṇḍa) gets an empty span at its neighbour’s end.

source

Ear.words

def words(
    rec, words
):

For each piece of rec and its list of displayed words, [word, start_ms, end_ms] per word.

These need the Su-śrotā checkpoint (520 MB) and the Vāgdhenu weights, so they do not run in the tests.

from vachaka.core import Chanter
ch, ear = Chanter(), Ear()
lines = ['वसुदेवसुतं देवं कंसचाणूरमर्दनम्', 'देवकीपरमानन्दं कृष्णं वन्दे जगद्गुरुम्']
r = best_of(partial(ch.chant, lines), ear, ' '.join(lines))
r.cer, ear.words(r, [l.split() for l in lines])
